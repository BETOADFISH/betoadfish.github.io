# 个人网站第 2、3 轮：版式与交互

## 第 2 轮：Yidu 桌面展示高度

建议：让幻灯片预览按内容决定高度，将制作步骤放在预览下方，避免宽屏将空白区域按固定比例一起放大。

原因为 `.slide-preview` 在桌面使用 `aspect-ratio: 16/11`，而其中的文字和卡片保持固定字号。随着视口变宽，容器高度增加，内容高度基本不变，空白集中在下半部。

执行：

- 桌面采用资料栏与幻灯片两列；预览使用内容高度，并为标题、论点与图块建立协调的字号。
- 流程放在下方。宽屏为四列，平板为两列，手机保留单列预览和两列流程按钮。
- 四步可以直接点击；播放只运行一遍，在完整页面上停下。加入暂停与重播。
- 减弱动态模式默认显示完成态，手动步骤仍可使用。
- 保留概括性重现的说明、来源检查与范围限定；图中没有增加客户材料。

## 第 3 轮：各页面独立的交互

保留白色、深绿、薄荷配色，Inter 字体、机构色和原卡片布局。交互与页面内容相连，避免每页都套用同一种入场动画。

| 页面 | 执行的交互 | 信息边界 |
| --- | --- | --- |
| 首页 | 研究地图可暂停与恢复轮播；点击一个项目后保持选中；离屏暂停 | 使用既有项目介绍和路径 |
| HuBisCO | 保留用户认可的 docking 回放与分子界面 | 既有分数、理论预测与尚未验证的限定不变 |
| PET hydrolase | 回放原始 A550 采样，可暂停、拖动记录时间、返回完整实验；切换底物后恢复完整曲线 | 默认显示完整记录；固定横纵轴；回放为加速展示，未插入模拟读数 |
| MCR-1 | 切换 NPN、PI、MALDI 所关注的检测层次，局部高亮及示意扫描可暂停 | 明确不代表实测轨迹或质谱；NPN 未可靠、PI 非外膜特异、MIC 不证明机制的限定保留 |
| 3D cell culture | 平面与三维空间切换、旋转和手动观察角度 | 图示仅呈现空间，不预测细胞表现或比较产品性能；七种产品的历史价格数据不变 |
| Yidu | 资料、论点、页面、检查四步演示 | 保留访谈观察、证据与分析判断的区分 |
| Tools | 点击选题、组卷、核对三个步骤，预览题目纸与评分标准的叠页变化；可直接打开题库 | 是流程预览，不作为已生成题卷显示 |

共用的播放逻辑会在组件离开视口、标签页进入后台、系统要求减弱动态或用户按下暂停时停止动画时钟。PET 的自动回放需要用户主动启动，首页、culture 和 MCR 也有本地暂停按钮。工具叠页仅响应点击。
